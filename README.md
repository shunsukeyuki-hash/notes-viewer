# ノートビューア（Googleドライブの PDF をAndroidで見るPWA）

GoodNotes（iOS）が Googleドライブに書き出した PDF を、Androidで **起動するたびに自動取得して表示** するウェブアプリです。

- 起動時に指定フォルダの PDF 一覧を取得（サブフォルダにも対応）
- タップで PDF を表示。ピンチで拡大可能
- 一度開いた PDF は端末に保存され、オフラインでも見られる
- 更新日時が変わった PDF は自動で取り直す

## セットアップ

### 1. Google の OAuth クライアント ID を作る（最初の1回だけ）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」→ **Google Drive API** を有効化
3. 「OAuth 同意画面」を設定
   - ユーザーの種類：外部
   - 公開ステータス：テスト
   - **テストユーザーに自分の Google アカウントを追加**
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元に、公開先のオリジンを追加
     （例：`https://ユーザー名.github.io`。パスは含めない）
5. 発行された **クライアント ID** を `config.js` に貼り付ける

### 2. ホスティングする（HTTPS が必須）

このフォルダの中身をそのまま置くだけです。無料の例：

- **GitHub Pages**：リポジトリに push → Settings → Pages
- **Cloudflare Pages / Netlify / Firebase Hosting**：フォルダをアップロード

### 3. Androidで使う

1. Chrome で公開URLを開く
2. ⋮ メニュー →「ホーム画面に追加」または「アプリをインストール」
3. アプリを開き、右上 ⚙ で **PDFを置いているドライブのフォルダURL** を貼り付けて保存
4. 「Googleでログイン」を押して許可（初回のみ）

以降は、起動すると自動でログイン状態を引き継いで一覧を取得します。

## GoodNotes 側の設定

GoodNotes の自動バックアップ先を Googleドライブにすると、PDF が自動でフォルダに保存されます（設定場所はGoodNotesのバージョンにより異なります）。手動なら「共有 → PDFを書き出し → Googleドライブ」でも構いません。

## 注意点

- 公開ステータスが「テスト」のままだと、**約7日ごとに再ログイン（再同意）** が必要になります。
  頻繁に出る場合は、同意画面を「本番環境」に切り替えてください（自分だけで使う場合は「未確認のアプリ」の警告が出ますが、「詳細」→「移動」で進めます）。
- 権限は `drive.readonly`（読み取り専用）です。ファイルを書き換えたり削除したりはしません。
- アクセストークンは約1時間で切れますが、アプリが自動で取り直します。
- 初回は **オンラインで一度起動し、PDFを1つ開いておく** と、以降オフラインでも動作します。
- 起動時の自動ログインが失敗したときは、画面上部に「Googleでログイン」ボタンが出ます。
- 内容を更新したいときは、右上の ⟳ ボタンで再取得できます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `config.js` | OAuth クライアント ID の設定 |
| `sw.js` | オフライン用のキャッシュ（Service Worker） |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加するための情報 |
